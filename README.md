## Особенности

- Базовые арифметические операции: сложение, вычитание, умножение, деление
- Возведение в квадрат (`x^2`), включая вложенное
- Поддержка скобок с автоматическим закрытием
- Ввод с клавиатуры и через кнопки интерфейса
- Безопасный парсер выражений на основе рекурсивного спуска (без `eval`)
- Вычисления в отдельном потоке — интерфейс не блокируется

## Стек

- **Python 3.7+**
- **PyQt6** — графический интерфейс
- Собственный парсер математических выражений (рекурсивный спуск)

## Как работает парсер

Вместо небезопасного `eval()` используется парсер на основе рекурсивного спуска. Он разбирает выражение по грамматике:

```
expression = term (('+' | '-') term)*
term       = factor (('*' | '/') factor)*
factor     = base ('^2')*
base       = NUMBER | '(' expression ')'
```

Это обеспечивает корректный приоритет операций и безопасность — выполняется только то, что явно поддерживается парсером.
